JHONA ARIZA PORTFOLIO 

Folder structure:
portfolio_no_bootstrap/
├── index.html
├── README.txt
├── css/
│   └── style.css
├── js/
│   └── main.js
└── img/
    └── (optional images you add)

How to run:
1. Extract the project folder.
2. Open index.html in a modern browser, or use VS Code with Live Server.
3. Edit text in index.html, styles in css/style.css, and interactions in js/main.js.

No Bootstrap, jQuery, icon pack, or other JavaScript framework is used. Google Fonts is loaded from the web; the page still works if it is unavailable.
The social profile URLs and portfolio website are placeholders. Update them before publishing.
The project visual tiles are CSS artwork; replace them with your own project screenshots if desired.
